# Depth Anything 3 (vendored)

Inference code of Depth Anything 3 by ByteDance Seed (https://github.com/ByteDance-Seed/Depth-Anything-3),
Apache-2.0, as used by Team XCore's Property Inspection Platform. Only the DA3-BASE model is used here
(`depth-anything/DA3-BASE` on Hugging Face, Apache-2.0); its weights download on first use. The Gaussian-splatting
head of the larger models (DA3-GIANT, CC BY-NC 4.0) is never loaded.
